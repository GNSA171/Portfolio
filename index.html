SecureFolder Locker

Modern high-security Windows desktop folder encryption suite engineered with authenticated AES-256-GCM chunked encryption, Argon2id key derivation, and crash-resilient transaction journaling.

C#.NET 8 LTSWPF (MVVM)AES-256-GCMArgon2idSQLitePathGuard SafetyZero-Knowledge
Architecture & Technical Highlights

Performs true in-place authenticated encryption using AES-256-GCM in 64 KB authenticated chunks with unique per-chunk nonces, ensuring no plaintext filenames or contents remain exposed on disk.

Master keys derived via memory-hard Argon2id (64 MB memory, 4 iterations, 4 parallelism lanes). Supports sub-second master password re-wrapping without re-encrypting underlying files.

Built with write-through transaction journaling in SQLite for automatic crash detection and recovery, ensuring interrupted operations safely roll back without data corruption. PathGuard engine strictly prevents locking critical system roots or junctions.

Packaged as a 100% offline, zero-knowledge, single-file portable Windows x64 executable requiring no installer, background services, or network connection.
